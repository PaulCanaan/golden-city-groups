# Research & Brainstorm

**Source inbox, created October 13, 2026 at Paul's request.** Drop brainstorming Canvases, teaching/research notes, permitted source files, or links to Notion knowledge here. Folder contents are local-only and gitignored except this guide because the repository is public. A dropped file is input, not approved direction or a published resource.

## Use

1. Drop the actual material here. When practical, use a name such as `YYYY-MM-DD Project Topic`; a polished brief is not required before capture.
2. Give the **Canvas Organizer** the files, project, and immediate question. It inspects the Canvas text, edges, and linked notes; preserves the original; and sorts source material, observations, proposals, and open questions.
3. It creates or updates the project's linked structure Canvas and development brief in [[06 Resources/Curriculum Development/02 Structure & Synthesize/README|02 Structure & Synthesize]]. Record which input files/Notion pages were used and which links or sources were unavailable.
4. It returns the organized map and specific questions to Paul. Paul confirms the intended direction or corrects the interpretation before selected ideas become teaching content.

If useful, copy [[10 Templates/Canvas/Curriculum Session Brainstorm.canvas|the blank brainstorming Canvas]] here and rename it for the real topic. Existing project development Canvases remain in phase 02; those are the maps the agents follow, while this folder receives rough inputs.

Keep original inputs until Paul confirms processing and their disposition. Do not delete, overwrite, or silently mark a source processed. Confidential participant/pastoral information remains outside this folder and this vault. If source material is suitable for public reuse, Paul can deliberately promote the selected material to a maintained project note; never force-add raw inbox files.

The existing sermon [[06 Resources/Resource Inbox/Resource Inbox|Resource Inbox]] and [[00 Dashboard/Inbox|ministry task Inbox]] retain their own responsibilities. This inbox is specifically for curriculum research and brainstorming.

See [[06 Resources/Curriculum Development/AI Agent Roles|AI Agent Roles]] and [[06 Resources/Curriculum Development/Ministry Curriculum Development|the full development workflow]].
