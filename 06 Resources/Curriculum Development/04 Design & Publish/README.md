## Design, Verify, and Release

1. The **Resource Producer** starts from the content Paul reviewed in phase 03 and applies [[06 Resources/Brand/Groups Resource Style|Groups Resource Style]]. Keep the actual editable source in phase 03 and link it from the project brief.
2. Generate the required output format using the appropriate document, presentation, or PDF skill. Inspect every actual exported page/slide for clipping, readability, writing space, sources, image/music rights where relevant, and agreement with the reviewed master. Fix and reopen the final candidate.
3. Prepare the concrete output for Paul to review. Design/export candidates remain in phase 03 until Paul confirms the final artifact; a filename containing `Final` is not approval.
4. **After Paul's final review is recorded, put the accepted edition here**, under its actual project and, for Collectives, separate Men's/Women's packages. Record the actual file, audience/date, source/master version, reviewer/date, and current edition in the phase 02 project brief.
5. When Paul authorizes distribution in the current task or a standing offering-specific instruction applies, publish/share through the established channel and record the real destination/result. Placement in this local library alone does not mean Church Center, Notion, or the public website has been updated. Never infer permission to message people or publish externally from a review checkbox.

## Library Practice

Use clear filenames with the project, audience where needed, study ID, actual gathering date, and resource type. Identify one current edition in the project brief; preserve approved editions and historical evidence deliberately rather than silently overwriting them. Reusable material retains the master/source link so later changes can regenerate its outputs.

Finished presentation files may be stored here when they are the accepted teaching edition, even though the editable production source remains linked in phase 03. Avoid creating extra export formats or duplicate copies without a real use.

The [[06 Resources/Resources Overview|Resources Overview]] links useful finished resources once they exist. No dummy release entry, new publication site, or external library has been created by this scaffold. Final curriculum-resource review remains distinct from offering readiness, appointments, and ministry governance.
