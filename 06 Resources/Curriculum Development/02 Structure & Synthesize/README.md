## Process and Human Review

The **Canvas Organizer** preserves and organizes actual input from phase 01 and linked Notion/source material. The **Curriculum Editor** follows the project Canvas through **Biblical Exegesis → Theological Synthesis → Formation Goals → Session Design** and records selected content, source references, unresolved claims, and the proposed resource scope in the brief and linked notes.

External research is allowed when a real gap needs it. Start with the supplied Bible, Notion notes, and designated course sources. Search primary sources, publisher/author material, and appropriate scholarly or church sources for the named question; read the material actually used, cite its location, and distinguish it from Paul's input. Record missing access rather than inventing book content or quotations. For Galatians, Keller remains primary for course development/questions and Peterson secondary for freedom.

Bring Paul into the process when source meaning, interpretation, audience formation goals, or session direction require his judgment. Return a concrete synthesis/outline and the smallest set of questions needed to resolve it. **Before moving selected content into phase 03, Paul confirms the synthesis, formation goals, and proposed gathering outline.** Record his actual response, date, and scope/version in the project brief using [[10 Templates/Records/Curriculum Project|the project record]]; no reply or elapsed time is not confirmation.

Unrelated source organization and research may continue while a decision is pending. Retained doctrinal/policy matters still follow Russ's existing authority; the agent roles create no new approver or curriculum decision. Copy only selected, traceable, public-suitable content into maintained notes.

After Paul confirms the direction, create the actual gathering master and editable content in [[06 Resources/Curriculum Development/03 Develop Content/README|03 Develop Content]]. Keep this project brief and structure Canvas here and link to the drafts rather than moving or duplicating the governing project record.
