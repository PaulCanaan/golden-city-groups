## Shared Workflow Structure

Use the existing Planted process as the practical pattern: **Document Status → Purpose / scope and ownership → process map with actions and completion conditions → detailed steps → communication / tools → implementation checks and boundaries → connections**. Scale the detail to the process. A checklist can be the detailed steps; do not create duplicate checklists solely to fill headings.

Distinguish recorded direction, proposals, implementation evidence, and open approvals. Every workflow keeps its start, owner, next step, and truthful completion condition. A template or checkbox cannot approve a ministry action.
