## Readiness Statuses

| Status | Meaning |
|---|---|
| **Ready** | Every stated criterion is supported by repository evidence, and any required approval is recorded. |
| **On Track** | Work has an owner and credible next step, no current dependency prevents progress, and available evidence supports the planned timing. |
| **In Progress** | Work has begun, but one or more stated criteria remain incomplete. |
| **Blocked** | The next required step cannot advance because a decision, approval, access, policy, person, or system dependency is missing. |
| **At Risk** | Work can advance, but timing, missing evidence, or an unresolved dependency could materially impair launch without intervention. |
| **Not Started** | The requirement applies, but the repository contains no evidence that implementation has begun. |
| **Not Applicable** | The requirement is outside the stated launch scope or explicitly deferred. |

`Ready` applies to the named deliverable only; it never implies that an entire offering is launch-ready.

Leader interest and follow-up can continue while these parallel tracks advance. Appointment, public listing, enrollment, and launch cannot bypass their applicable gates.
