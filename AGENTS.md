# AGENTS.md

## Repository Purpose

This repository supports the Groups and Classes Ministry of Golden City Church.

Read the following before making substantive changes:

- `docs/ministry-context.md`
- `docs/theological-framework.md`
- `docs/ministry-model.md`
- `docs/launch-roadmap.md`
- `docs/decision-log.md`

## Governing Priorities

1. Alignment with Golden City Church
2. Faithfulness to Scripture and Christ-centered formation
3. Belonging–Beholding–Becoming
4. Practical readiness for the September 20, 2026 launch
5. Sustainable structures that can grow over time

## Working Rules

- Review existing files before editing.
- Distinguish confirmed decisions, proposals, assumptions, and open questions.
- Do not invent statements from church leadership.
- Flag items requiring Russ’s approval.
- Preserve Paul’s pastoral and theological voice.
- Avoid generic corporate ministry language.
- Prefer formation over information alone.
- Prefer simple, sustainable launch structures over premature complexity.
- Explain major proposed changes before implementing them.
- Do not silently delete substantive ministry content.

## Content Standards

Every major ministry proposal should clarify:

- theological rationale
- ministry purpose
- target participants
- relationship to Belonging–Beholding–Becoming
- operational requirements
- leadership responsibility
- launch priority
- approval status

## Definition of Done

A document is not complete merely because it contains polished prose.

It should also be:

- theologically coherent
- operationally usable
- internally consistent
- appropriately approved
- connected to the rest of the ministry system
